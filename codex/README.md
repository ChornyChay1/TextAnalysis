# Лабораторная №2

Основной файл: [lab2.ipynb](lab2.ipynb). Все пояснения, таблицы, графики и десять схем зависимостей находятся внутри ноутбука.

## Запуск

Из корня репозитория:

```bash
python -m pip install -r codex/requirements.txt
python -m notebook
```

1. Открыть `lab1/notebook.ipynb` и выполнить ячейки до «Сохранение данных для лабораторной №2» включительно. Ячейка стоит сразу после очистки текста; выполнять остальные вычисления первой лабораторной для экспорта не требуется.
2. Открыть `codex/lab2.ipynb` и выполнить все ячейки сверху вниз.

Рабочая папка ядра — корень репозитория или папка самого ноутбука. Для первой лабораторной, как в её исходной версии, рабочая папка должна быть `lab1` (путь к CSV — `../data/Tweets.csv`).

Первый ноутбук сохраняет `data/lab1/documents.jsonl` и `manifest.json`: исходные тексты, классы, индексы CSV, Train/Test и очищенные токены до исправления опечаток. Второй проверяет контрольную сумму экспорта. Случайное разбиение повторно не создаётся.

spaCy разбирает исходный текст после декодирования HTML и выравнивания пробелов. Текст не восстанавливается из `[USER]`, стемов или `[UNK]`: это исказило бы грамматику и скрывало ошибки на сленге. По заданию №2 статистики считаются по всему корпусу, включая Test; они описательные, без обучения классификатора.

Результаты сохраняются в `data/lab2`: распределения POS, шесть разобранных ошибок, пары аспект/прилагательное, топ-20, ссылки местоимений и изменённые тексты. Десять деревьев сохраняются в SVG и отображаются внутри ноутбука. При наличии CairoSVG также сохраняются PNG; эта библиотека необязательна. Каталог `data` исключён из Git существующим `.gitignore`.

Частоты частей речи между классами сравниваются в процентах, а не только по абсолютным числам. Примеры ошибок теггера проверены на модели `en_core_web_sm 3.8.0`. Разрешение анафоры — учебное правило с ошибками; доля найденных кандидатов не является точностью. У английских существительных грамматический род часто отсутствует в разметке, что явно учитывается.

## Проверка

Все восемь кодовых ячеек выполнены последовательно в одном процессе Python на 14 640 твитах; фактические текстовые и графические выводы сохранены в `.ipynb`. Отдельно проверены отрицание в оценке, согласование числа и исключение относительного that. Запуск отдельного ядра Jupyter в среде подготовки заблокирован ограничением локальных соединений; интерфейс Jupyter здесь не проверялся.
