# Анализ текстов — лабораторная №1

Датасет: [Twitter US Airline Sentiment](https://www.kaggle.com/datasets/crowdflower/twitter-airline-sentiment). Текстовая колонка `text`, метка для стратификации `airline_sentiment`. Исходные данные доступны по лицензии CC BY-NC-SA 4.0; CSV в репозиторий не добавлен.

## Запуск

```bash
python -m pip install -r lab1/requirements.txt
python lab1/lab1.py
```

При первом запуске скрипт скачает `Tweets.csv` в `data/`, а NLTK загрузит WordNet и английский определитель частей речи. Вывод появится в `results/report.md`, `results/lengths.png`, `results/stopwords.png`. Для заранее скачанного CSV используйте `--data путь/к/Tweets.csv`; для другой папки результатов — `--output путь`. Требуется доступ к сети только при первой загрузке данных и ресурсов NLTK.

Порядок: стратифицированное разбиение → статистика Train → исследование шума и регулярная очистка → сравнение словарей → поиск похожих слов собственным алгоритмом Левенштейна → обучение биграмм на Train → перплексия Test и генерация. Результаты считаются на фиксированном разбиении (`random_state=42`); Test не участвует в подборе словаря или обучении.

В `report.md` приведены формулы, рассчитанные показатели, графики и пять образцов генерации. Слова в пары отбираются по частоте и близости написания: это кандидаты для ручной проверки, включая возможные разные словоформы.
